## 狀態定義

- `未開始`：情境所需程式尚未完成。
- `已實作`：情境所需程式已完成，但尚未取得執行證據。
- `已驗證`：已依情境實際執行並確認結果，於備註記錄證據。
- `待真實樣本`：程式與既有樣本已通過，仍等待尚未取得的實際資料。
- `使用者已驗收`：使用者已在實際遊玩流程中確認。
- `已移除`：需求規格已取消此情境，代號保留不再使用。

「依賴」欄標示需要 `.references/` 樣本或第 16 章待確認事項才能完整驗證的情境。
