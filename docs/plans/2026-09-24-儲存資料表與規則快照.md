# 儲存資料表與規則快照 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `src/storage/` 建立 Dexie 資料庫與遊戲局，並把資料列彙整成核心的輸入：規則輸入快照、血統樹，以及姊妹、種牡馬紀錄、正式後繼、替代母馬與既有馬匹（技術設計 4.3）。

**Architecture:** 儲存的三個子計畫中的第 1 個（資料表與規則快照 → 事件與寫入操作 → 備份、檢查點與封存）。資料列保存目前狀態並建立索引，事件歷程由子計畫 2 加入。彙整分兩層：`snapshot.ts`、`mating.ts`、`inputs.ts` 是把資料列組成核心輸入的純函式；`loaders.ts` 在唯讀交易內查詢 Dexie，再交給純函式。資料表與彙整方式以技術設計 4.3 為準。

**Tech Stack:** TypeScript（strict）、Dexie 4、Vitest、fake-indexeddb。不新增套件。

## Global Constraints

- 成品：`app/dist/WPStudBook.html` 單一檔案，Windows 最新版 Edge 與 Chrome 以 `file://` 離線使用；執行時不依賴 CDN、網路、本機伺服器或擴充功能。（AGENTS.md）
- TypeScript strict，維持 TypeScript 6.x。`src/` 的 `lib` 是 ES2022：不要用 `findLast`、`toSorted`、`Object.groupBy` 這類 ES2023 以後的方法。`verbatimModuleSyntax` 已開啟：只當型別用的匯入要寫 `type`。

> - **目前狀態由歷程彙整**：年齡、最新代數、群組數量等可推導的資料不重複人工維護。

**6.4、7.1、7.2 馬名、系與系統對照表**

> - 繁殖牝馬與種牡馬馬名經匯入確認後唯讀；匯入時同一身分馬名不同，列為衝突並略過。手動輸入、尚未經匯入確認的馬名可以更正，保存更正歷程（例：11.6 的名稱不符）。
> - 同時保存完整馬名（第 1 欄）與去除 `(外)`、`[地]` 前綴的基本馬名，主要顯示完整馬名，兩者都可搜尋。產駒名稱見 9.4。

> - 新系只能在 7.3 指定的位置成立。開啟建立新系的分支時，填寫目前子系統、親系統、零代市場種牡馬與代表色（自動分配，可修改）；零代市場種牡馬可手動建立或匯入目標種牡馬 TXT（11.9），他本身的父系由 TXT 帶入，手動建立時可填（10.2 用來推定他父親的系統）。同一層新系可分年建立。
> - 位置與內部識別固定；目前子系統與親系統名稱可隨遊戲更新，保存變更年份與原名稱。

> - 子系統升格時由使用者更新，保存變更年份。
> - **分出來源**：對照表可為每個子系統記錄它原本從哪一個子系統獨立出來（選填）。子系統與某匹馬同名時，那匹馬就是該系統的始祖；始祖的父親屬於分出來源，用於 10.2 推定。

**7.6、7.7 斷血補系與種牡馬**

> - **補系**：保存斷血的系、原因、年度、中斷的公系或母系、補入的市場親馬、採用的其他系血統與重新加入的產駒。補入親馬為零代，產駒承接下一代（例：第 5 系 12 代斷血，補系產出 13 代）；補入的是零代市場種牡馬時，原則配自家母馬，不足時可例外補入市場母馬（7.3）。原支線歷史保留，其餘七系不受影響。
> - **補公系**：第 p 系 N 代沒有種牡馬可以延續時，以該系零代市場種牡馬代替第 p 系 N 代種牡馬，配原本指定的配對系 N 代母馬群，產出第 p 系 N+1 代（例：第 5 系零代 × 第 1 系 12 代母馬群 → 第 5 系 13 代）。宣告後，第 p 系 N+1 代的指定配對固定為補公系配對，之後重試得到第 p 系 N 代種牡馬也不另列一般任務；要用他配種請登記為自由配種，或更正補系宣告。第 p 系 N 代已有在崗或已指定的種牡馬時不能補公系（等待目標種牡馬不算斷血，7.8）（2026-09-23 決定）；第 p 系還沒到達 N 代（N 代沒有種牡馬紀錄，母馬群也沒成立，應原地重試或對 N−1 代補公系），或 N+1 代已有種牡馬紀錄時，也不能補公系（2026-09-24 決定）。
> - **補系結束**：補系產駒接上後繼時結束並解除暫停：補公系為產出的那一代有了種牡馬紀錄（指定預定後繼即可）；補母系為補系任務產出的那一代母馬群成立（2026-09-23 決定）。

> - **現任**：每系每代同時只有一匹在崗種牡馬；交接期間同系上下兩代可同時在崗。狀態為在崗、已被取代、退出生產行列、已引退；退出生產行列與已引退都由使用者標示；種牡馬總表不偵測離場（11.8）。
> - **預定後繼**：每系可指定一匹，就緒狀態為尚未誕生、競走中、已引退待指定、正式供用。尚未出生時可指定已受胎、產駒尚未出生的八系指定配種；產駒出生後不自動改指，由使用者確認，產駒為牝時提醒預定後繼失效。正式接任後，相關母馬下次配種改為指定配種並列為高優先待辦。
> - **史實種牡馬提前引退**：建立新系或補系所選的市場種牡馬被遊戲提前引退時，使用者標示引退，再從市場選同系其他種牡馬替換（手動建立或匯入目標種牡馬 TXT），沿用原系位置與分支、同為零代，產駒系與代數不變。子系統不同時警告並確認，確認後更新目前子系統名稱；親系統也不同時一併提示影響活血。替換前該分支任務顯示「缺少目標種牡馬」並暫停。

**4.6、8.1～8.3、8.5、8.9 繁殖牝馬**

> - 匯入檔 `年` 欄是馬齡，出生當年為 0 歲，每年 1 月加 1。

> 繁殖圈是據點 `32`～`35` 在養的母馬。「來源」與「目前狀態」分開保存並可同時顯示：來源為結構化事件（市場創系、市場補血、市場混血、市場補系、所屬競走馬引退轉入、其他，可附備註）；狀態為生產中或已離圈（售出、定年引退）。

> - 某代第一匹自家母駒以暫定保留或正式保留轉入時，該代立即成立；成立後不可回溯，母馬離圈只改目前狀態。

> - 市場母馬記錄替代的系與代數（建系起點記為第 1 系起點用）；自身父系可為八系以外或留空，不得改寫成替代系。畫面顯示「替代第 q 系」或「第 1 系起點用」，不得顯示為她屬於該系。
> - 替代母馬的親系統會跟後代 3 代前的其他祖先撞在一起時，警告並確認（10.3），因為活血會少於 8 種。判斷方式：自身父系經系統對照表取得的親系統，符合下列任一項：
>   - 與第 q 系以外任一已成立系目前的親系統相同。
>   - 與同一代、替代其他系的市場母馬親系統相同（她們會一起出現在後代的 3 代前）。替代同一系的母馬之間不比較。

> - 定年可調，預設 25 歲。達定年減 1 歲（預設 24 歲）時提示「最後值得配種的年齡」；達定年時不列入任務。
> - **高齡提醒**：母馬達到高齡提醒年齡（可調，預設 18 歲）時，提示「產駒素質可能下降，可考慮出售」（依據見 4.6）。只提示，不影響任何操作。

> - 狀態：暫定保留、候選、正式保留、已被取代、已售出。自家母駒轉入時，姊妹不在圈內 → 暫定保留；已有姊妹在圈 → 候選。
> - 暫定保留、候選、正式保留都可列入任務；已被取代、已售出不列入。

**9.1、9.5、9.6、10.2、10.4 配種、後繼與血統**

> - 每匹母馬每年一筆：配種類型（八系指定、自由配種；建系期依 7.3 分支進行的配種也屬八系指定）、實際種牡馬、受胎狀態、預定生產年、產駒連結、規則快照、血統檢查與確認紀錄。可事先登記，或由七月匯入自動建立（11.6）。

> 一律待售、不可成為八系後繼、不取得八系的系，不因性別、能力或母馬所屬群改變；父母、出生年與名稱照常保存，售出後仍可從母馬紀錄查到。

> - 進入母馬群或接任前再次核對父母、系與代數，不符時阻止。

> - **推定父親的系統**：一匹馬的系統跟著父親走。3 代前祖先中，沒有內部紀錄的父親，以其子女本身紀錄的父系推定系統（例：替代第 5 系市場母馬的父親，依她的自身父系；零代市場種牡馬的父親，依他本身的父系，沒填時才用該系的子系統），畫面標示「推定」。
> - 例外：未知位置只來自建系期的市場種牡馬或替代母馬（主要在產出 5 代）時，只提示不要求確認。

> - 被父母、產駒或後繼引用的馬匹不得物理刪除，只能改狀態或更正資料。

**12.1、12.2、12.5 資料保存**

> - 多個遊戲局彼此隔離，所有操作只作用於目前遊戲局。保存名稱、版本、起始年、目前遊戲年、建立與更新時間、最近備份時間。
> - 目前遊戲年只由使用者更新（手動，或匯入時確認推進），不依電腦日期；更新前顯示影響並確認。
> - 新局可全新空白，或只複製系統對照表與顯示設定。

> - IndexedDB 是日常資料庫，只更新受影響的紀錄；主要資料不存 localStorage。
> - 完整備份與移轉用 JSON／JSON.GZ（支援 Compression Streams 時優先 `.json.gz`，否則 `.json`）。資料契約含格式識別、結構版本、應用版本、匯出時間、遊戲局摘要、各集合與筆數、SHA-256；識別存字串，正規化集合，不內嵌血緣樹。備份不含檢查點：檢查點只供本機回溯，還原成的新局從之後的年度匯入重新累積（2026-09-24 決定）。

> - 設計目標為單局數萬筆紀錄（不是遊戲上限），繁殖圈與母馬群規模不設上限。
> - 常用查詢建索引：局；系、代數與在圈狀態；能力番号與出生年；父母；出生年；待補馬名；匯入類型、年與時點；事件對象與年。

**技術設計 4.1、4.2 模組邊界與核心的輸入約定**

> | 儲存 | `src/storage/` | Dexie 資料庫、套用計畫的單一交易寫入、檢查點、備份與還原、持久保存、備份資料夾 | `core` |

> 依賴方向以 ESLint 的 `no-restricted-imports` 強制：`core` 不得引用其他模組；`ce-import` 與 `storage` 只能引用 `core`；沒有模組可以引用 `ui`。

> 核心不定義資料表結構，也不保存狀態。規則以「規則輸入快照」為輸入，快照由儲存層依資料表彙整：

> - 八個系位置各一筆：是否已開啟（建系起點或建立新系時已填寫系統與零代市場種牡馬，需求規格 7.1），以及各代種牡馬狀態與各代母馬群。
> - 種牡馬狀態每（系, 代）一個值（需求規格 7.7）：在崗；已指定但還沒正式供用（尚未誕生、競走中、已引退待指定）；已離場，指退出生產行列或已引退、而且同一代沒有其他在崗或已指定的種牡馬。
> - 母馬群每（系, 代）一筆：是否已成立（第一匹自家母駒以暫定或正式保留轉入，需求規格 8.2，依 `establishesGeneration` 判斷；只有替代母馬時為未成立）、列入任務的母馬數（依 `mareListedInTasks`：在繁殖圈內、未達定年，自家母駒還要是暫定保留、候選或正式保留），以及其中的自家母馬數（建立新系時由使用者判斷自家母馬是否不足，需求規格 7.3；不得多於列入任務的母馬數）。母馬歸哪個母馬群依 `damPlacement`：自家母駒依出生紀錄的系與代數，替代母馬依她替代的系與代數，起點母馬歸第 1 系起點母馬群；待指定用途的市場母馬（需求規格 8.4）與自由配種所生的母駒（11.5）不屬於任何母馬群，不計入。
> - 第 1 系 0 代母馬群就是第 1 系起點母馬群。
> - 已宣告的斷血補系（需求規格 7.6）：每系一份清單，每筆是斷血的代數與斷掉的一方（公系或母系）；補公系另帶補入的零代市場種牡馬狀態（與種牡馬狀態同樣三種，還沒選定時留空）。代數要在該系成立的代數以後，同一系同一代同一方只有一筆；使用者更正（撤銷）宣告時從清單移除。補入的零代市場種牡馬不放進該系的種牡馬狀態，零代那一格仍是建系時的零代市場種牡馬。補系結束後這一筆仍留在清單，因為補公系配對永久取代一般配對。補入的零代市場種牡馬依 7.7 提前引退並替換時，狀態取替換後那一匹，比照零代那一格。補公系配對產出 4 代以內（建系期）時，補入的零代市場種牡馬算 10.2 的建系期市場種牡馬，血統樹的建系期標記為是；循環期補入的不算（使用者 2026-09-24 決定）。
> - 系統對照表：每個子系統一筆，含親系統與選填的分出來源；分出來源只用在始祖例外（10.2）。
> - 八系目前的系統：每個系位置的目前子系統與親系統，系尚未開啟時兩者都沒有值。
> - 血統樹：一次配種往上四代，每個位置是一匹馬或「沒有內部紀錄」。每匹馬帶內部識別（判斷 4 代內重複）、馬名（判斷始祖例外，10.2）、本身的父系，以及是不是建系期的市場馬（零代市場種牡馬或替代母馬，10.2 的例外判斷用）。
> - 零代市場種牡馬的父系欄留空時，儲存層彙整快照時改填該系目前的子系統（需求規格 10.2）；核心只看快照裡的父系，不另外查系位置。

> - **到達某代**：該系該代有種牡馬紀錄（任何狀態），或該代母馬群已成立。只有替代母馬的母馬群不算。

> - **同一匹馬**（`identity.ts`）：只傳目前遊戲局的馬匹，馬番号不參與判斷。能力番号由匯入層與手動輸入統一寫法後保存與比對，`0x0000` 是有效值。馬名與父母名稱用基本馬名；還不是正式馬名的名稱（四月的「母馬名の0歳」、未命名的產駒）不傳。手動輸入、尚未經匯入確認的馬名要標 `manualName`：只用來輔助配對，與匯入名稱不同時不算衝突，由匯入名稱取代（需求規格 6.4、9.4、BRD-09）；經匯入確認的馬名不同時仍是衝突（ID-08）。兩邊都有值而且不同才算「明顯不符」，比較時忽略前後空白。以馬名輔助配對時，候選是馬名相符、出生年相同或未填的紀錄；候選兩筆以上，或能力番号與出生年配到兩筆以上，都列為衝突（需求規格 11.5「無法判斷的身分列入衝突」）；輔助配對到的紀錄父母明顯不符也是衝突；以馬名配到的紀錄已有不同的能力番号時也是衝突，不得覆寫。同一匯入檔內重複的能力番号由 `duplicateAbilityNumbers` 列出，只看能力番号、不看出生年，有任何一個時整份停止套用。一月總表以父馬、母馬、出生年配對舊產駒（11.3）屬於匯入層。
> - **姊妹接替**（`sisters.ts`）：同父同母以父母的內部識別判斷，任一方不明就不算姊妹。「在圈」指在繁殖圈內，被取代但還沒賣出的姊妹也算。選定正式保留時，只把在圈而且列入任務的姊妹改為已被取代。輸入有在圈但狀態是已售出的母馬時丟 `RangeError`。
> - **母馬的年齡與列入任務**（`mares.ts`）：定年與高齡提醒年齡由儲存層從設定帶入，預設 25、18 歲。高齡提醒只在未達定年時顯示，因為已達定年的母馬不能賣出（需求規格 4.6）。五月缺席的預設原因只看上次五月的馬齡，被取代的姊妹也照同一條規則；馬齡不明時預設售出。列入任務時馬齡不明當作未達定年。出售母親提醒只看暫定保留或正式保留的女兒。馬齡不是 0 以上的整數時丟 `RangeError`。
> - **種牡馬**（`stallions.ts`）：兄弟比較以比較對象（通常是現任）為準，選入的要同系、同代、同父，任一方的父馬不明就不算同父。選定現任只把同系同代原本在崗的一匹改為已被取代；前任、後任、生效年與原因由儲存層保存。市場種牡馬替換零代種牡馬，或補公系補入零代市場種牡馬（需求規格 7.6）時，比較他本身的父系與該系目前的子系統，父系不明時不警告；他的子系統沒登錄在對照表、查不到親系統時，仍回報親系統不同，讓畫面提示補登。現任的提醒年齡由設定帶入，預設 26 歲。`StallionStatus` 的 `retired` 是種牡馬已引退；預定後繼的「已引退待指定」（競走馬已引退、還沒接任）對應 `status` 留空，不是 `retired`，否則 `chooseIncumbent` 會拒絕接任。
> - **正式後繼**（`successor.ts`）：用出生紀錄連結的配種紀錄的規則快照（實際種牡馬的系與代數、母馬當時的身分）核對，不用母馬目前的用途，因為用途修改從下一次配種才生效（需求規格 8.4）。除了父母與重算的系與代數，也以 10.3 確認這次配種是出生紀錄那一代的指定配對，所以偏離規則配到別系種牡馬的產駒會被阻止（5.2；10.3「刻意偏離請登記為自由配種」，使用者 2026-09-23 確認）。沒有配種紀錄、或配到八系以外種牡馬的產駒比照自由配種。`verifySuccessor` 的第二個參數是要進入的母馬群，或要接任、指定為預定後繼的系與代數，與出生紀錄不符時阻止。補公系所生的產駒，配種紀錄的規則快照要記 `restoration`，以補公系配對核對（需求規格 7.6）；補母系所生的產駒是一般指定配對，照常核對。

**技術設計 4.3 儲存（本計畫依據的設計，已和使用者確認）**

> - 資料表依需求規格的實體劃分（見下方「資料表」）。索引照需求規格 12.5；除了全域的 `meta`，每張表都帶遊戲局欄位，所有查詢以遊戲局為前提。識別用 `crypto.randomUUID()` 產生的字串（12.2）。IndexedDB 不能以布林值建立索引，要查詢的狀態存成字串。
> - 資料列保存目前狀態（在圈、接替狀態、種牡馬狀態、用途、據點），供索引查詢；每次變更另外寫一筆事件作為歷程（需求規格 5.3）。年齡、母馬群匹數、代的成立、是否到達某代等可推導的值不保存，彙整規則輸入快照時計算。
> - 結構版本用 Dexie 的版本升級管理；備份檔的結構版本與遷移沿用同一套版本號。正式發布前結構版本維持 1，各計畫直接修改版本 1 的結構；第一次發布後才以版本升級變更。
> - 檢查點：整局資料以 gzip 壓縮後存入檢查點表，記錄年、時點、時間與 SHA-256（12.4）。
>

> #### 規則輸入快照的彙整
>
> 4.2 各項核心輸入由儲存層依下列方式彙整。彙整分兩層：純函式把資料列組成核心的輸入，讀取函式負責查詢 Dexie。年齡以遊戲局的目前遊戲年計算。讀取時找不到遊戲局，或資料列之間的關聯斷掉，丟出帶識別的錯誤（第 5 章的預期外失敗）。
>
> - **系統**：系統對照表取 `systems`。八系目前的系統固定八筆：已開啟的系，子系統取 `lines`，親系統查對照表，查不到時留空。
> - **種牡馬狀態**：依 `stallions` 中不屬於補系的任用。同系同代有在崗的為在崗；否則有狀態留空的（預定後繼）為已指定；否則為已離場。沒有任用時不產生那一格，所以 4.2「任何狀態的種牡馬紀錄」就是 `stallions` 有沒有那一系那一代的任用。
> - **母馬群**：依 `mares` 的用途分群，待指定用途與自由配種所生的母馬不分群。已成立看「是否使該代成立」：以暫定保留或正式保留轉入時設為是，之後不改回（需求規格 8.2「成立後不可回溯」）；以候選轉入的不算。列入任務的匹數依 `mareListedInTasks` 計算，另計其中的自家母馬數。母馬全部離圈的群仍然列出，才能顯示「已成立，母馬群待補」。
> - **補系**：不含已撤銷的宣告。補公系補入的種牡馬狀態以同樣規則，只看屬於這次補系的任用；還沒選定時留空。
> - **血統樹**：從配種雙方往上展開到第 4 代。馬名用基本馬名。零代市場種牡馬（含補公系補入的）父系留空時，改填該系目前的子系統。建系期標記：建系起點與建立新系的零代市場種牡馬（含依 7.7 替換上來的）一律為是，補公系補入的只在補公系配對產出 4 代以內時為是；母馬依目前的用途，第 1 系起點用或替代 3 代以內時為是。用途在配種後才修改的少數情況，標記跟著新用途，只影響 10.2 的例外是提示還是要求確認。
> - **姊妹**（`OwnMare`）：同父同母的自家母馬。
> - **種牡馬紀錄**（`StallionRecord`）：某系某代的任用。
> - **正式後繼**（`SuccessorCandidate`）：產駒的父母，加上出生紀錄連結的配種紀錄的規則快照；沒有配種紀錄、自由配種或沒有規則快照時比照自由配種。
> - **替代母馬**（`SubstituteMare`，需求規格 8.3）：同一代的替代母馬包含已離圈的，因為她已生的產駒仍會出現在後代的 3 代前；這項檢查只警告，多算一匹的代價比漏掉警告小。
> - **既有馬匹**（`KnownHorse`）：父母名優先用保存的匯入名稱，沒有才用連結馬匹的基本馬名；追蹤名與「母馬名の0歳」不是正式馬名，不傳。
> - **年齡設定**：定年、高齡提醒年齡與種牡馬提醒年齡取自 `settings`。

## 本計畫的詮釋

需求規格與技術設計沒有逐字寫出、由本計畫決定的地方。技術設計 4.3 的詮釋已經和使用者確認；下面是本計畫在程式層級的決定，審查時請逐條對照上一節的原文。

1. **資料列的欄位**（`records.ts`）：欄位名稱與型別照 Task 1。母馬的用途分成 `own`、`substitute`、`start`、`unassigned`、`free` 五種，所屬母馬群另存 `groupLine`、`groupGeneration`：自家母駒是出生紀錄的系與代數，替代母馬是她替代的系與代數，起點母馬記為第 1 系 0 代（技術設計 4.2「第 1 系 0 代母馬群就是第 1 系起點母馬群」），所以同一個索引就能查每個母馬群。`damRoleOf` 把這三欄轉回 core 的 `DamRole`，三欄互相矛盾時丟 `RangeError`。
2. **是否使該代成立**存成 `establishedGeneration` 布林值，只看自家母駒；什麼時候設為 true 由子計畫 2 的轉入與回歸負責，本計畫只讀。
3. **種牡馬任用**（`stallions`）：每一列都直接存系與代數。尚未誕生的預定後繼沒有馬匹，改存受胎的配種紀錄（`breedingId`），系與代數是那次配種的預計產出；已誕生、還沒正式供用的預定後繼狀態留空，另存就緒（`racing` 競走中、`retired-awaiting` 已引退待指定）。
4. **配種紀錄**一匹母馬一年一筆，以唯一索引 `&[gameId+mareId+year]` 保證（需求規格 9.1）。規則快照照 7.4 存距離、實際種牡馬的系與代數、母馬配種當時的身分、預計產出，補公系配對另記 `restoration: true`；血統檢查結果與確認紀錄由子計畫 2 加入。
5. **索引**：本計畫建立 12.5 中欄位已經存在的索引：局（每張表的 `gameId`）、能力番号與出生年、父母、出生年、系與代數與在圈狀態（`mares` 的 `[gameId+groupLine+groupGeneration]` 與 `[gameId+herd]`），另加輔助配對用的基本馬名（6.2）與種牡馬任用的 `[gameId+line+generation]`。待補馬名、匯入類型與時點、事件對象與年的索引，由加入那些欄位的計畫建立。
6. **遊戲局**：局名去除前後空白後不能是空的、起始年要是整數，否則丟 `RangeError`；目前遊戲年從起始年開始。「只複製設定」複製 `settings` 整列與 `systems` 全部（12.1「只複製系統對照表與顯示設定」），要複製的局不存在時整個交易取消、不建立新局。遊戲局依建立時間排序。目前使用的局存在 `meta` 的 `currentGame`，切換時確認該局存在。最近備份時間由子計畫 3 加入 `games`。
7. **錯誤**：讀取函式找不到遊戲局或設定，或資料列之間的關聯斷掉（母馬、任用或父母指到不存在或屬於其他局的馬，出生紀錄指到不存在或屬於其他局的配種紀錄）時丟 `Error`，訊息附識別。純函式在資料列內容互相矛盾（用途與母馬群欄位、自家母駒沒有接替狀態、配種紀錄不是產駒出生紀錄連結的那一筆）時丟 `RangeError`。純函式只檢查自己用到的資料：八系快照只替在圈母馬查馬匹（算馬齡）；`loadRuleSnapshot` 則替所有母馬讀馬匹，所以資料庫裡任何一匹母馬的馬匹不見都會發現。
8. **讀取的一致性**：要查兩張以上資料表的讀取函式，都在一個唯讀交易內讀完。
9. **血統樹**：同一匹馬同時是建系的零代市場種牡馬與循環期補公系補入的種牡馬時，建系期標記為是（任一次零代任用符合就算）；父系改填時取他零代任用所在的系。
10. **種牡馬紀錄**：`loadStallionRecords` 以 `restorationId` 區分：留空時讀該系該代的一般任用，指定時讀那一次補公系補入的任用（補入的種牡馬依 7.7 替換時用）。尚未誕生的預定後繼沒有馬匹，不列入。
11. **正式後繼**：只有「八系指定配種、有規則快照、產駒的出生紀錄有系與代數」三者都成立時，才當作八系指定配種所生；否則比照自由配種。
12. **替代母馬**：`exceptHorseId` 排除正在檢查的母馬本身（修改用途時她已經有資料列）。
13. **既有馬匹**：`manualName` 一律是布林值，只有馬名來源是手動輸入時為 true。
14. **測試資料庫**：`fake-indexeddb` 每次用新的 `IDBFactory`，測試之間完全隔離；`addTestGame` 直接寫入識別固定為 `G` 的局（目前遊戲年 1990），方便搭配 `app/tests/support/rows.ts` 的資料列產生器。

```ts
import { DEFAULT_MARE_AGE_SETTINGS } from '../core/mares'
import { DEFAULT_STALLION_REMINDER_AGE } from '../core/stallions'
import type { WPStudBookDatabase } from './database'
import type { GameRow, SettingsRow, SystemRow } from './records'

/** 新局的預設設定（需求規格 7.7、8.5） */
export const DEFAULT_SETTINGS: Readonly<Omit<SettingsRow, 'gameId'>> = {
  retirementAge: DEFAULT_MARE_AGE_SETTINGS.retirementAge,
  seniorAge: DEFAULT_MARE_AGE_SETTINGS.seniorAge,
  stallionReminderAge: DEFAULT_STALLION_REMINDER_AGE,

/** meta 表中記錄目前遊戲局的鍵 */
const CURRENT_GAME_KEY = 'currentGame'

export interface NewGame {
  name: string
  startYear: number
  /** 從這一局只複製系統對照表與設定（需求規格 12.1）；留空時全新空白 */
  copyFrom?: string
}

/**
 * 建立遊戲局（需求規格 12.1）：全新空白，或只複製另一局的系統對照表與設定，
 * 不複製八系位置、馬匹或歷程（DATA-13）。目前遊戲年從起始年開始，局名去除前後空白。
 * 局名空白或起始年不是整數時丟出 RangeError；要複製的局不存在時丟出錯誤，不建立新局。
 */
export async function createGame(
  db: WPStudBookDatabase,
  input: NewGame,
  now: Date = new Date(),
): Promise<GameRow> {
  const name = input.name.trim()
  if (name === '') throw new RangeError('局名不能空白')
  if (!Number.isInteger(input.startYear)) {
    throw new RangeError(`起始年必須是整數：${input.startYear}`)
  }
  const timestamp = now.toISOString()
  const game: GameRow = {
    id: crypto.randomUUID(),
    name,
    startYear: input.startYear,
    currentYear: input.startYear,
    createdAt: timestamp,
    updatedAt: timestamp,
  }
  await db.transaction('rw', [db.games, db.settings, db.systems], async () => {
    let settings: SettingsRow = { gameId: game.id, ...DEFAULT_SETTINGS }
    let systems: SystemRow[] = []
    if (input.copyFrom !== undefined) {
      await loadGame(db, input.copyFrom)
      settings = { ...(await loadSettings(db, input.copyFrom)), gameId: game.id }
      const source = await db.systems.where('gameId').equals(input.copyFrom).toArray()
      systems = source.map((row) => ({ ...row, gameId: game.id }))
    }
    await db.games.add(game)
    await db.settings.add(settings)
    await db.systems.bulkAdd(systems)
  })
  return game
}

/** 所有遊戲局，依建立時間排序 */
export async function listGames(db: WPStudBookDatabase): Promise<GameRow[]> {
  const games = await db.games.toArray()
  return games.sort((a, b) => a.createdAt.localeCompare(b.createdAt))
}

/** 讀取遊戲局；找不到時丟出錯誤 */
export async function loadGame(db: WPStudBookDatabase, gameId: string): Promise<GameRow> {
  const game = await db.games.get(gameId)
  if (!game) throw new Error(`找不到遊戲局：${gameId}`)
  return game
}

/** 讀取一局的設定；找不到時丟出錯誤 */
export async function loadSettings(db: WPStudBookDatabase, gameId: string): Promise<SettingsRow> {
  const settings = await db.settings.get(gameId)
  if (!settings) throw new Error(`找不到遊戲局的設定：${gameId}`)
  return settings
}

/** 目前使用的遊戲局；還沒選過時為 undefined（需求規格 12.1：所有操作只作用於目前遊戲局） */
export async function currentGameId(db: WPStudBookDatabase): Promise<string | undefined> {
  return (await db.meta.get(CURRENT_GAME_KEY))?.value
}

/** 切換目前遊戲局；遊戲局不存在時丟出錯誤 */
export async function setCurrentGame(db: WPStudBookDatabase, gameId: string): Promise<void> {
  await db.transaction('rw', [db.games, db.meta], async () => {
    await loadGame(db, gameId)
    await db.meta.put({ key: CURRENT_GAME_KEY, value: gameId })
  })
}
```

```ts
import type {
  EightLineSnapshot,
  MareGroupSlot,
  RestorationSlot,
  StallionSlot,
  StallionState,
} from '../core/board'
import { damPlacement, type DamRole } from '../core/generation'
import { LINE_POSITIONS, type LinePosition } from '../core/lines'
import { ageInYear, mareListedInTasks, type MareAgeSettings } from '../core/mares'
import type { SisterStatus } from '../core/sisters'
import { parentSystemOf, type LineSystemSnapshot, type SystemTable } from '../core/systems'
import type { HorseRow, LineRow, MareRow, RestorationRow, StallionRow, SystemRow } from './records'

// 把資料列組成核心的規則輸入快照（技術設計 4.2、4.3「規則輸入快照的彙整」）。全部是純函式。

/** 系統對照表（需求規格 7.2） */
export function buildSystemTable(rows: readonly SystemRow[]): SystemTable {
  return rows.map(({ subsystem, parentSystem, origin }) =>
    origin === undefined ? { subsystem, parentSystem } : { subsystem, parentSystem, origin },
  )
}

/** 八系目前的系統，固定八筆：已開啟的系，子系統取系位置，親系統查對照表，查不到時留空 */
export function buildLineSystems(
  lines: readonly LineRow[],
  table: SystemTable,
): LineSystemSnapshot {
  return LINE_POSITIONS.map((line) => {
    const subsystem = lines.find((row) => row.line === line)?.subsystem ?? null
    return { line, subsystem, parentSystem: parentSystemOf(table, subsystem) }
  })
}

/**
 * 同一格（某系某代，或某次補公系）的任用彙整成種牡馬狀態（需求規格 7.7）：
 * 有在崗的為在崗；否則有狀態留空的（預定後繼）為已指定；否則為已離場。沒有任用時回傳 undefined。
 */
export function stallionState(rows: readonly StallionRow[]): StallionState | undefined {
  return rows.length === 0 ? undefined : occupiedState(rows)
}

/** 至少有一筆任用時的種牡馬狀態 */
function occupiedState(rows: readonly StallionRow[]): StallionState {
  if (rows.some((row) => row.status === 'active')) return 'active'
  if (rows.some((row) => row.status === undefined)) return 'waiting'
  return 'ended'
}

/**
 * 母馬在規則上的身分（需求規格 8.2、8.3）；待指定用途與自由配種所生的母馬不屬於任何母馬群，回傳 null。
 * 用途與母馬群欄位矛盾時丟出 RangeError：自家與替代母馬缺少系或代數、起點母馬不在第 1 系 0 代、
 * 不屬於母馬群的母馬帶有系或代數。
 */
export function damRoleOf(mare: MareRow): DamRole | null {
  const { usage, groupLine: line, groupGeneration: generation } = mare
  if (usage === 'unassigned' || usage === 'free') {
    if (line !== undefined || generation !== undefined) {
      throw new RangeError(`不屬於母馬群的母馬不能有系或代數：${mare.horseId}`)
    }
    return null
  }
  if (line === undefined || generation === undefined) {
    throw new RangeError(`母馬缺少所屬母馬群的系或代數：${mare.horseId}`)
  }
  if (usage === 'start') {
    if (line !== 1 || generation !== 0) {
      throw new RangeError(`起點母馬必須在第 1 系 0 代：${mare.horseId}`)
    }
    return { kind: 'start' }
  }
  return usage === 'own'
    ? { kind: 'own', line, generation }
    : { kind: 'substitute', forLine: line, forGeneration: generation }
}

/** 彙整八系快照需要的資料列 */
export interface EightLineRows {
  lines: readonly LineRow[]
  stallions: readonly StallionRow[]
  mares: readonly MareRow[]
  /** 至少包含在圈母馬的馬匹資料，用來算馬齡 */
  horses: readonly HorseRow[]
  restorations: readonly RestorationRow[]
}

/**
 * 規則輸入快照（技術設計 4.2「規則輸入快照」、4.3「規則輸入快照的彙整」）。
 * year 是目前遊戲年，用來算馬齡；settings 是這一局的母馬年齡設定。
 * 在圈母馬找不到馬匹資料、自家母駒缺少接替狀態時丟出錯誤。
 */
export function buildEightLineSnapshot(
  rows: EightLineRows,
  year: number,
  settings: MareAgeSettings,
): EightLineSnapshot {
  const horses = new Map(rows.horses.map((horse) => [horse.id, horse]))
  return {
    lines: LINE_POSITIONS.map((line) => ({
      line,
      opened: rows.lines.some((row) => row.line === line),
      stallions: stallionSlots(
        rows.stallions.filter((row) => row.line === line && row.restorationId === undefined),
      ),
      mareGroups: mareGroupSlots(line, rows.mares, (mare) => listed(mare, horses, year, settings)),
      restorations: restorationSlots(line, rows.restorations, rows.stallions),
    })),
  }
}

/** 同一系不屬於補系的任用，依代數分格 */
function stallionSlots(rows: readonly StallionRow[]): StallionSlot[] {
  const generations = [...new Set(rows.map((row) => row.generation))].sort((a, b) => a - b)
  return generations.map((generation) => ({
    generation,
    state: occupiedState(rows.filter((row) => row.generation === generation)),
  }))
}

/** 第 line 系的母馬群，依代數排序；母馬全部離圈的群仍然列出 */
function mareGroupSlots(
  line: LinePosition,
  mares: readonly MareRow[],
  isListed: (mare: MareRow) => boolean,
): MareGroupSlot[] {
  const groups = new Map<number, MareRow[]>()
  for (const mare of mares) {
    const role = damRoleOf(mare)
    if (!role) continue
    const placement = damPlacement(role)
    const group = placement.kind === 'start' ? { line: 1, generation: 0 } : placement
    if (group.line !== line) continue
    groups.set(group.generation, [...(groups.get(group.generation) ?? []), mare])
  }
  return [...groups.entries()]
    .sort(([a], [b]) => a - b)
    .map(([generation, members]) => {
      const active = members.filter(isListed)
      return {
        generation,
        established: members.some((mare) => mare.usage === 'own' && mare.establishedGeneration),
        activeMares: active.length,
        ownMares: active.filter((mare) => mare.usage === 'own').length,
      }
    })
}

/** 母馬是否列入任務（需求規格 8.5、8.9）；不在圈的母馬不必查馬匹資料 */
function listed(
  mare: MareRow,
  horses: ReadonlyMap<string, HorseRow>,
  year: number,
  settings: MareAgeSettings,
): boolean {
  if (mare.herd !== 'in-herd') return false
  const horse = horses.get(mare.horseId)
  if (!horse) throw new Error(`找不到母馬的馬匹資料：${mare.horseId}`)
  const age = horse.birthYear === undefined ? undefined : ageInYear(horse.birthYear, year)
  return mareListedInTasks({ inHerd: true, age, sisterStatus: sisterStatusOf(mare) }, settings)
}

/** 自家母駒的接替狀態；市場母馬留空。自家母駒沒有接替狀態時丟出 RangeError */
function sisterStatusOf(mare: MareRow): SisterStatus | undefined {
  if (mare.usage !== 'own') return undefined
  if (mare.sisterStatus === undefined) {
    throw new RangeError(`自家母駒缺少接替狀態：${mare.horseId}`)
  }
  return mare.sisterStatus
}

/**
 * 第 line 系已宣告的補系，不含已撤銷的；依代數排序，同一代補公系在前。
 * 補公系補入的種牡馬狀態只看屬於這次補系的任用，還沒選定時留空。
 */
function restorationSlots(
  line: LinePosition,
  restorations: readonly RestorationRow[],
  stallions: readonly StallionRow[],
): RestorationSlot[] {
  return restorations
    .filter((row) => row.line === line && !row.revoked)
    .sort((a, b) => a.generation - b.generation || sideOrder(a) - sideOrder(b))
    .map((row): RestorationSlot => {
      if (row.side === 'dam') return { side: 'dam', generation: row.generation }
      const state = stallionState(stallions.filter((stallion) => stallion.restorationId === row.id))
      return state === undefined
        ? { side: 'sire', generation: row.generation }
        : { side: 'sire', generation: row.generation, stallion: state }
    })
}

function sideOrder(row: RestorationRow): number {
  return row.side === 'sire' ? 0 : 1
}
```

```ts
import type { EightLineSnapshot } from '../core/board'
import type { LineSystemSnapshot, SystemTable } from '../core/systems'
import type { WPStudBookDatabase } from './database'
import { loadGame, loadSettings } from './games'
import type { HorseRow } from './records'
import { buildEightLineSnapshot, buildLineSystems, buildSystemTable } from './snapshot'

// 讀取 Dexie、交給純函式組成核心的輸入（技術設計 4.3「規則輸入快照的彙整」）。
// 找不到遊戲局，或資料列之間的關聯斷掉時，丟出帶識別的錯誤（技術設計第 5 章的預期外失敗）。

/** 任務看板與規則檢查共用的規則輸入（技術設計 4.2） */
export interface RuleSnapshot {
  eightLines: EightLineSnapshot
  systemTable: SystemTable
  lineSystems: LineSystemSnapshot
}

/** 讀取一局的規則輸入快照；在同一個唯讀交易內讀完，資料一致。年齡以目前遊戲年計算 */
export async function loadRuleSnapshot(
  db: WPStudBookDatabase,
  gameId: string,
): Promise<RuleSnapshot> {
  return db.transaction(
    'r',
    [
      db.games,
      db.settings,
      db.lines,
      db.systems,
      db.stallions,
      db.mares,
      db.horses,
      db.restorations,
    ],
    async () => {
      const game = await loadGame(db, gameId)
      const settings = await loadSettings(db, gameId)
      const [lines, systems, stallions, mares, restorations] = await Promise.all([
        db.lines.where('gameId').equals(gameId).toArray(),
        db.systems.where('gameId').equals(gameId).toArray(),
        db.stallions.where('gameId').equals(gameId).toArray(),
        db.mares.where('gameId').equals(gameId).toArray(),
        db.restorations.where('gameId').equals(gameId).toArray(),
      ])
      const horses = await loadHorses(
        db,
        gameId,
        mares.map((mare) => mare.horseId),
      )
      const systemTable = buildSystemTable(systems)
      return {
        eightLines: buildEightLineSnapshot(
          { lines, stallions, mares, horses, restorations },
          game.currentYear,
          settings,
        ),
        systemTable,
        lineSystems: buildLineSystems(lines, systemTable),
      }
    },
  )
}

/** 依識別讀取同一局的馬匹；找不到或屬於其他局時丟出錯誤 */
async function loadHorses(
  db: WPStudBookDatabase,
  gameId: string,
  ids: readonly string[],
): Promise<HorseRow[]> {
  const rows = await db.horses.bulkGet([...ids])
  return rows.map((row, index) => {
    if (!row || row.gameId !== gameId) throw new Error(`找不到馬匹：${ids[index]}`)
    return row
  })
}
```

```ts
import { BUILD_PHASE_LAST_GENERATION, type LinePosition } from '../core/lines'
import {
  CLOSE_GENERATIONS,
  type Mating,
  type PedigreeHorse,
  type PedigreeNode,
} from '../core/pedigree'
import type { HorseRow, LineRow, MareRow, RestorationRow, StallionRow } from './records'
import { damRoleOf } from './snapshot'

/** 組血統樹需要的資料列 */
export interface PedigreeRows {
  /** 至少包含樹上的每一匹馬：配種雙方往上到第 4 代 */
  horses: readonly HorseRow[]
  /** 樹上的馬的種牡馬任用 */
  stallions: readonly StallionRow[]
  /** 樹上的馬的母馬資料 */
  mares: readonly MareRow[]
  restorations: readonly RestorationRow[]
  lines: readonly LineRow[]
}

/**
 * 一次配種的血統樹（需求規格 10.2；技術設計 4.3「規則輸入快照的彙整」的血統樹）：
 * 從種牡馬與母馬往上展開到第 4 代，第 5 代不展開。沒有內部紀錄的父母為 null。
 * 樹上的馬找不到資料、零代市場種牡馬所在的系沒有開啟、補公系任用找不到宣告時丟出錯誤。
 */
export function buildMating(
  sireId: string | undefined,
  damId: string | undefined,
  rows: PedigreeRows,
): Mating {
  const horses = new Map(rows.horses.map((horse) => [horse.id, horse]))
  const node = (id: string | undefined, depth: number): PedigreeNode | null => {
    if (id === undefined) return null
    const horse = horses.get(id)
    if (!horse) throw new Error(`找不到馬匹：${id}`)
    const expand = depth < CLOSE_GENERATIONS
    return {
      horse: pedigreeHorse(horse, rows),
      sire: expand ? node(horse.sireId, depth + 1) : null,
      dam: expand ? node(horse.damId, depth + 1) : null,
    }
  }
  return { sire: node(sireId, 1), dam: node(damId, 1) }
}

/**
 * 血統樹上的一匹馬：馬名用基本馬名。零代市場種牡馬（含補公系補入的）父系留空時，
 * 改填他所在系目前的子系統（需求規格 10.2）。
 */
function pedigreeHorse(horse: HorseRow, rows: PedigreeRows): PedigreeHorse {
  const zeroGeneration = rows.stallions.filter(
    (row) => row.horseId === horse.id && row.generation === 0,
  )
  const mare = rows.mares.find((row) => row.horseId === horse.id)
  const firstZero = zeroGeneration[0]
  return {
    id: horse.id,
    name: horse.baseName,
    sireSystem:
      horse.sireSystem ??
      (firstZero === undefined ? undefined : currentSubsystem(firstZero.line, rows.lines)),
    buildPhaseMarket:
      zeroGeneration.some((row) => buildPhaseStallion(row, rows.restorations)) ||
      (mare !== undefined && buildPhaseMare(mare)),
  }
}

function currentSubsystem(line: LinePosition, lines: readonly LineRow[]): string {
  const row = lines.find((candidate) => candidate.line === line)
  if (!row) throw new Error(`零代市場種牡馬所在的第 ${line} 系沒有開啟`)
  return row.subsystem
}

/**
 * 建系期的零代市場種牡馬（需求規格 10.2）：建系起點與建立新系的（含依 7.7 替換上來的）一律是；
 * 補公系補入的只在補公系配對產出 4 代以內時是（使用者 2026-09-24 決定）
 */
function buildPhaseStallion(row: StallionRow, restorations: readonly RestorationRow[]): boolean {
  if (row.restorationId === undefined) return true
  const restoration = restorations.find((candidate) => candidate.id === row.restorationId)
  if (!restoration) throw new Error(`找不到補系宣告：${row.restorationId}`)
  return restoration.generation + 1 <= BUILD_PHASE_LAST_GENERATION
}

/**
 * 建系期的替代母馬（需求規格 10.2）：依目前的用途，第 1 系起點用，
 * 或替代的代數讓產駒在 4 代以內（替代 3 代以內）
 */
function buildPhaseMare(mare: MareRow): boolean {
  const role = damRoleOf(mare)
  if (role?.kind === 'start') return true
  return role?.kind === 'substitute' && role.forGeneration + 1 <= BUILD_PHASE_LAST_GENERATION
}
```

```ts
import type { EightLineSnapshot } from '../core/board'
import { CLOSE_GENERATIONS, type Mating } from '../core/pedigree'
import type { LineSystemSnapshot, SystemTable } from '../core/systems'
import type { WPStudBookDatabase } from './database'
import { loadGame, loadSettings } from './games'
import { buildMating } from './mating'
import type { HorseRow, MareRow } from './records'
import { buildEightLineSnapshot, buildLineSystems, buildSystemTable } from './snapshot'

// 讀取 Dexie、交給純函式組成核心的輸入（技術設計 4.3「規則輸入快照的彙整」）。
// 找不到遊戲局，或資料列之間的關聯斷掉時，丟出帶識別的錯誤（技術設計第 5 章的預期外失敗）。

/** 任務看板與規則檢查共用的規則輸入（技術設計 4.2） */
export interface RuleSnapshot {
  eightLines: EightLineSnapshot
  systemTable: SystemTable
  lineSystems: LineSystemSnapshot
}

/** 讀取一局的規則輸入快照；在同一個唯讀交易內讀完，資料一致。年齡以目前遊戲年計算 */
export async function loadRuleSnapshot(
  db: WPStudBookDatabase,
  gameId: string,
): Promise<RuleSnapshot> {
  return db.transaction(
    'r',
    [
      db.games,
      db.settings,
      db.lines,
      db.systems,
      db.stallions,
      db.mares,
      db.horses,
      db.restorations,
    ],
    async () => {
      const game = await loadGame(db, gameId)
      const settings = await loadSettings(db, gameId)
      const [lines, systems, stallions, mares, restorations] = await Promise.all([
        db.lines.where('gameId').equals(gameId).toArray(),
        db.systems.where('gameId').equals(gameId).toArray(),
        db.stallions.where('gameId').equals(gameId).toArray(),
        db.mares.where('gameId').equals(gameId).toArray(),
        db.restorations.where('gameId').equals(gameId).toArray(),
      ])
      const horses = await loadHorses(
        db,
        gameId,
        mares.map((mare) => mare.horseId),
      )
      const systemTable = buildSystemTable(systems)
      return {
        eightLines: buildEightLineSnapshot(
          { lines, stallions, mares, horses, restorations },
          game.currentYear,
          settings,
        ),
        systemTable,
        lineSystems: buildLineSystems(lines, systemTable),
      }
    },
  )
}

/**
 * 讀取一次配種的血統樹（需求規格 10.2）：從種牡馬與母馬往上一代一代批次讀到第 4 代；
 * 近親重複的馬只讀一次。樹上的馬找不到或屬於其他局時丟出錯誤。
 */
export async function loadMating(
  db: WPStudBookDatabase,
  gameId: string,
  sireId: string | undefined,
  damId: string | undefined,
): Promise<Mating> {
  return db.transaction(
    'r',
    [db.horses, db.stallions, db.mares, db.restorations, db.lines],
    async () => {
      const horses: HorseRow[] = []
      const loaded = new Set<string>()
      let ids = uniqueIds([sireId, damId])
      for (let depth = 1; depth <= CLOSE_GENERATIONS && ids.length > 0; depth++) {
        const rows = await loadHorses(db, gameId, ids)
        horses.push(...rows)
        rows.forEach((row) => loaded.add(row.id))
        ids = uniqueIds(rows.flatMap((row) => [row.sireId, row.damId])).filter(
          (id) => !loaded.has(id),
        )
      }
      const horseIds = horses.map((horse) => horse.id)
      const [stallions, mares, restorations, lines] = await Promise.all([
        db.stallions.where('horseId').anyOf(horseIds).toArray(),
        db.mares.bulkGet(horseIds),
        db.restorations.where('gameId').equals(gameId).toArray(),
        db.lines.where('gameId').equals(gameId).toArray(),
      ])
      return buildMating(sireId, damId, {
        horses,
        stallions,
        mares: mares.filter((mare): mare is MareRow => mare !== undefined),
        restorations,
        lines,
      })
    },
  )
}

/** 去掉留空與重複的識別 */
function uniqueIds(ids: readonly (string | undefined)[]): string[] {
  return [...new Set(ids.filter((id): id is string => id !== undefined))]
}

/** 依識別讀取同一局的馬匹；找不到或屬於其他局時丟出錯誤 */
async function loadHorses(
  db: WPStudBookDatabase,
  gameId: string,
  ids: readonly string[],
): Promise<HorseRow[]> {
  const rows = await db.horses.bulkGet([...ids])
  return rows.map((row, index) => {
    if (!row || row.gameId !== gameId) throw new Error(`找不到馬匹：${ids[index]}`)
    return row
  })
}
```

```ts
import type { KnownHorse } from '../core/identity'
import type { MareAgeSettings } from '../core/mares'
import type { OwnMare } from '../core/sisters'
import type { StallionRecord } from '../core/stallions'
import type { SubstituteMare } from '../core/substitute'
import type { SuccessorCandidate } from '../core/successor'
import type { BreedingRow, HorseRow, MareRow, SettingsRow, StallionRow } from './records'
import { damRoleOf, ownSisterStatus } from './snapshot'

// 規則輸入快照以外的核心輸入（技術設計 4.3「規則輸入快照的彙整」）。全部是純函式。

/** 母馬的年齡設定（需求規格 8.5），取自這一局的設定 */
export function mareAgeSettings(settings: SettingsRow): MareAgeSettings {
  return { retirementAge: settings.retirementAge, seniorAge: settings.seniorAge }
}

/**
 * 判斷姊妹接替用的自家母駒（需求規格 8.9）：mares 中用途為自家母駒的，帶上馬匹記載的父母。
 * 找不到馬匹資料或缺少接替狀態時丟出錯誤。
 */
export function buildOwnMares(mares: readonly MareRow[], horses: readonly HorseRow[]): OwnMare[] {
  const byId = horseMap(horses)
  return mares
    .filter((mare) => mare.usage === 'own')
    .map((mare) => {
      const horse = requireHorse(byId, mare.horseId)
      return {
        id: mare.horseId,
        sireId: horse.sireId,
        damId: horse.damId,
        inHerd: mare.herd === 'in-herd',
        status: ownSisterStatus(mare),
      }
    })
}

/**
 * 兄弟比較與選定現任用的種牡馬紀錄（需求規格 7.7）：有馬匹的任用，帶上馬匹記載的父馬；
 * 尚未誕生的預定後繼沒有馬匹，不列入。找不到馬匹資料時丟出錯誤。
 */
export function buildStallionRecords(
  stallions: readonly StallionRow[],
  horses: readonly HorseRow[],
): StallionRecord[] {
  const byId = horseMap(horses)
  return stallions.flatMap((row) => {
    if (row.horseId === undefined) return []
    const horse = requireHorse(byId, row.horseId)
    return [
      {
        id: row.horseId,
        placement: { line: row.line, generation: row.generation },
        sireId: horse.sireId,
        status: row.status,
      },
    ]
  })
}

/**
 * 正式後繼核對用的產駒（需求規格 9.6）：產駒記載的父母，加上出生紀錄連結的配種紀錄的規則快照。
 * 沒有配種紀錄、自由配種、沒有規則快照，或出生紀錄沒有系與代數時，比照自由配種。
 * breeding 不是這匹產駒出生紀錄連結的配種紀錄時丟出 RangeError。
 */
export function buildSuccessorCandidate(
  foal: HorseRow,
  breeding: BreedingRow | undefined,
): SuccessorCandidate {
  if (breeding && foal.birth?.breedingId !== breeding.id) {
    throw new RangeError(`配種紀錄 ${breeding.id} 不是產駒 ${foal.id} 的出生紀錄`)
  }
  const parents = { sireId: foal.sireId, damId: foal.damId }
  const placement = foal.birth?.placement
  const rule = breeding?.kind === 'designated' ? breeding.rule : undefined
  if (!breeding || !rule || !placement) return { ...parents, origin: { kind: 'free' } }
  return {
    ...parents,
    origin: {
      kind: 'designated',
      breedingSireId: breeding.sireId,
      breedingDamId: breeding.mareId,
      sire: rule.sire,
      dam: rule.dam,
      recorded: placement,
      restoration: rule.restoration,
    },
  }
}

/**
 * 8.3 親系統檢查用的同代替代母馬：替代第 generation 代的市場母馬，包含已離圈的，
 * 因為她已生的產駒仍會出現在後代的 3 代前（技術設計 4.3）。
 * exceptHorseId 是正在檢查的母馬本身（例如修改用途時），不和自己比較。找不到馬匹資料時丟出錯誤。
 */
export function buildSubstituteMares(
  mares: readonly MareRow[],
  horses: readonly HorseRow[],
  generation: number,
  exceptHorseId?: string,
): SubstituteMare[] {
  const byId = horseMap(horses)
  return mares.flatMap((mare) => {
    const role = damRoleOf(mare)
    if (role?.kind !== 'substitute' || role.forGeneration !== generation) return []
    if (mare.horseId === exceptHorseId) return []
    const horse = requireHorse(byId, mare.horseId)
    return [
      {
        forLine: role.forLine,
        forGeneration: role.forGeneration,
        ownSireSystem: horse.sireSystem,
      },
    ]
  })
}

/**
 * 身分比對用的既有馬匹（需求規格 6.2；技術設計 4.2「身分、母馬、種牡馬與後繼」）：只傳同一局的馬。
 * 馬名只傳正式馬名的基本馬名；父母名優先用保存的匯入名稱，沒有才用連結馬匹的基本馬名。
 * 連結的父母不在 horses 中時丟出錯誤。
 */
export function buildKnownHorses(horses: readonly HorseRow[]): KnownHorse[] {
  const byId = horseMap(horses)
  const parentName = (name: string | undefined, id: string | undefined) =>
    name ?? (id === undefined ? undefined : requireHorse(byId, id).baseName)
  return horses.map((horse) => ({
    id: horse.id,
    abilityNumber: horse.abilityNumber,
    birthYear: horse.birthYear,
    name: horse.baseName,
    manualName: horse.nameSource === 'manual',
    sireName: parentName(horse.sireName, horse.sireId),
    damName: parentName(horse.damName, horse.damId),
  }))
}

function horseMap(horses: readonly HorseRow[]): Map<string, HorseRow> {
  return new Map(horses.map((horse) => [horse.id, horse]))
}

function requireHorse(horses: ReadonlyMap<string, HorseRow>, id: string): HorseRow {
  const horse = horses.get(id)
  if (!horse) throw new Error(`找不到馬匹：${id}`)
  return horse
}
```

```ts
// 找不到遊戲局，或資料列之間的關聯斷掉時，丟出帶識別的錯誤（技術設計第 5 章的預期外失敗）。

/** 任務看板與規則檢查共用的規則輸入（技術設計 4.2） */
export interface RuleSnapshot {
  eightLines: EightLineSnapshot
  systemTable: SystemTable
  lineSystems: LineSystemSnapshot

/** 讀取一局的規則輸入快照；在同一個唯讀交易內讀完，資料一致。年齡以目前遊戲年計算 */
export async function loadRuleSnapshot(
  db: WPStudBookDatabase,
  gameId: string,
): Promise<RuleSnapshot> {
  return db.transaction(
    'r',
    [
      db.games,
      db.settings,
      db.lines,
      db.systems,
      db.stallions,
      db.mares,
      db.horses,
      db.restorations,
    ],
    async () => {
      const game = await loadGame(db, gameId)
      const settings = await loadSettings(db, gameId)
      const [lines, systems, stallions, mares, restorations] = await Promise.all([
        db.lines.where('gameId').equals(gameId).toArray(),
        db.systems.where('gameId').equals(gameId).toArray(),
        db.stallions.where('gameId').equals(gameId).toArray(),
        db.mares.where('gameId').equals(gameId).toArray(),
        db.restorations.where('gameId').equals(gameId).toArray(),
      ])
      const horses = await loadHorses(
        db,
        gameId,
        mares.map((mare) => mare.horseId),
      )
      const systemTable = buildSystemTable(systems)
      return {
        eightLines: buildEightLineSnapshot(
          { lines, stallions, mares, horses, restorations },
          game.currentYear,
          settings,
        ),
        systemTable,
        lineSystems: buildLineSystems(lines, systemTable),
      }
    },
  )

/**
 * 讀取一次配種的血統樹（需求規格 10.2）：從種牡馬與母馬往上一代一代批次讀到第 4 代；
 * 近親重複的馬只讀一次。樹上的馬找不到或屬於其他局時丟出錯誤。
 */
export async function loadMating(
  db: WPStudBookDatabase,
  gameId: string,
  sireId: string | undefined,
  damId: string | undefined,
): Promise<Mating> {
  return db.transaction(
    'r',
    [db.horses, db.stallions, db.mares, db.restorations, db.lines],
    async () => {
      const horses: HorseRow[] = []
      const loaded = new Set<string>()
      let ids = uniqueIds([sireId, damId])
      for (let depth = 1; depth <= CLOSE_GENERATIONS && ids.length > 0; depth++) {
        const rows = await loadHorses(db, gameId, ids)
        horses.push(...rows)
        rows.forEach((row) => loaded.add(row.id))
        ids = uniqueIds(rows.flatMap((row) => [row.sireId, row.damId])).filter(
          (id) => !loaded.has(id),
        )
      }
      const horseIds = horses.map((horse) => horse.id)
      const [stallions, mares, restorations, lines] = await Promise.all([
        db.stallions.where('horseId').anyOf(horseIds).toArray(),
        db.mares.bulkGet(horseIds),
        db.restorations.where('gameId').equals(gameId).toArray(),
        db.lines.where('gameId').equals(gameId).toArray(),
      ])
      return buildMating(sireId, damId, {
        horses,
        stallions,
        mares: mares.filter((mare): mare is MareRow => mare !== undefined),
        restorations,
        lines,
      })
    },
  )
}

/**
 * 讀取同父同母的自家母駒（需求規格 8.9），用在轉入時的接替狀態與選定正式保留。
 * 父母任一方不明時不算姊妹，回傳空陣列。
 */
export async function loadSisters(
  db: WPStudBookDatabase,
  gameId: string,
  sireId: string | undefined,
  damId: string | undefined,
): Promise<OwnMare[]> {
  if (sireId === undefined || damId === undefined) return []
  return db.transaction('r', [db.horses, db.mares], async () => {
    const horses = await db.horses
      .where('[gameId+damId]')
      .equals([gameId, damId])
      .filter((horse) => horse.sireId === sireId)
      .toArray()
    const mares = await db.mares.bulkGet(horses.map((horse) => horse.id))
    return buildOwnMares(
      mares.filter((mare): mare is MareRow => mare !== undefined),
      horses,
    )
  })
}

/**
 * 讀取第 line 系第 generation 代的種牡馬紀錄（需求規格 7.7），用在兄弟比較與選定現任。
 * restorationId 留空時是該系該代的一般任用；指定時是那一次補公系補入的任用。
 */
export async function loadStallionRecords(
  db: WPStudBookDatabase,
  gameId: string,
  line: LinePosition,
  generation: number,
  restorationId?: string,
): Promise<StallionRecord[]> {
  return db.transaction('r', [db.stallions, db.horses], async () => {
    const rows = await db.stallions
      .where('[gameId+line+generation]')
      .equals([gameId, line, generation])
      .filter((row) => row.restorationId === restorationId)
      .toArray()
    const horses = await loadHorses(
      db,
      gameId,
      rows.flatMap((row) => row.horseId ?? []),
    )
    return buildStallionRecords(rows, horses)
  })
}

/**
 * 讀取正式後繼核對用的產駒（需求規格 9.6）。
 * 產駒找不到、出生紀錄連結的配種紀錄找不到或屬於其他局時丟出錯誤。
 */
export async function loadSuccessorCandidate(
  db: WPStudBookDatabase,
  gameId: string,
  foalId: string,
): Promise<SuccessorCandidate> {
  return db.transaction('r', [db.horses, db.breedings], async () => {
    const foal = await loadHorse(db, gameId, foalId)
    const breedingId = foal.birth?.breedingId
    if (breedingId === undefined) return buildSuccessorCandidate(foal, undefined)
    const breeding = await db.breedings.get(breedingId)
    if (!breeding || breeding.gameId !== gameId) {
      throw new Error(`找不到配種紀錄：${breedingId}`)
    }
    return buildSuccessorCandidate(foal, breeding)
  })
}

/**
 * 讀取替代第 generation 代的市場母馬（需求規格 8.3），包含已離圈的；exceptHorseId 是正在檢查的母馬本身
 */
export async function loadSubstituteMares(
  db: WPStudBookDatabase,
  gameId: string,
  generation: number,
  exceptHorseId?: string,
): Promise<SubstituteMare[]> {
  return db.transaction('r', [db.mares, db.horses], async () => {
    const mares = await db.mares
      .where('gameId')
      .equals(gameId)
      .filter((mare) => mare.usage === 'substitute' && mare.groupGeneration === generation)
      .toArray()
    const horses = await loadHorses(
      db,
      gameId,
      mares.map((mare) => mare.horseId),
    )
    return buildSubstituteMares(mares, horses, generation, exceptHorseId)
  })
}

/** 讀取身分比對用的既有馬匹（需求規格 6.2）：只讀這一局的馬 */
export async function loadKnownHorses(
  db: WPStudBookDatabase,
  gameId: string,
): Promise<KnownHorse[]> {
  return buildKnownHorses(await db.horses.where('gameId').equals(gameId).toArray())
}

/** 去掉留空與重複的識別 */
function uniqueIds(ids: readonly (string | undefined)[]): string[] {
  return [...new Set(ids.filter((id): id is string => id !== undefined))]
}

/** 讀取同一局的一匹馬；找不到或屬於其他局時丟出錯誤 */
async function loadHorse(db: WPStudBookDatabase, gameId: string, id: string): Promise<HorseRow> {
  const horse = await db.horses.get(id)
  if (!horse || horse.gameId !== gameId) throw new Error(`找不到馬匹：${id}`)
  return horse
}

/** 依識別讀取同一局的馬匹；找不到或屬於其他局時丟出錯誤 */
async function loadHorses(
  db: WPStudBookDatabase,
  gameId: string,
  ids: readonly string[],
): Promise<HorseRow[]> {
  const rows = await db.horses.bulkGet([...ids])
  return rows.map((row, index) => {
    if (!row || row.gameId !== gameId) throw new Error(`找不到馬匹：${ids[index]}`)
    return row
  })
}
```
